A brand-new portfolio site — pure static HTML, CSS and JavaScript with GSAP animations. No build step, no framework.

## Features

- Animated hero and scroll scenes powered by GSAP
- Work showcase with live project links
- Fully responsive, fast static pages
- No build step — what you see is what ships

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **GSAP** (ScrollTrigger, Draggable, DrawSVG)
- **jQuery**

## Run Locally

No build step — just open `index.html`, or serve the folder:

```bash
python3 -m http.server
```
